# Simple SQL Database

This folder contains a small SQLite example.

Files:
- `simple_database.sql`: SQL script to create tables, insert sample rows, and run a query.
- `create_simple_db.py`: Python script to execute the SQL and create `simple.db`.

Run:

```bash
cd "LF 5 SQL"
python3 create_simple_db.py
```

Then open `simple.db` with any SQLite browser or use `sqlite3 simple.db`.
